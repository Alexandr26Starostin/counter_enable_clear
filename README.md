# counter

## Описание модуля

В этом проекте представлена реализация счётчика. Размер счётчика можно варировать. Счётчик синхронизован с положительным фронтом clk_i (Но для увеличения нужно, чтобы был выставлен флаг, разрешающий продолжать счёт). Имеется флаг переполнения счётчика. Также есть асинхронный (с clk_i) as_reset_i (Обнуляет значение счётчика и флага переполнения по отрицательному фронту + блокирует счёт, пока выставлен в 0). Симуляция производилась в программе Vivado 2019.1. Осуществлялась прошивка FPGA: Basys3.  Более подробно про модуль можно узнать в [https://github.com/Alexandr26Starostin/counter_enable_clear/blob/master/TEX/cnt_en_clr.pdf](отчёте).
